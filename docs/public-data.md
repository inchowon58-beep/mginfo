# 공공데이터 (data.go.kr)

글에 붙는 지역 숫자(동물병원·미용·음식점·숙박·보호소 등)는 **저장본**입니다. Vercel 요청 경로에서 data.go.kr을 호출하지 않습니다. 호출하면 요금·쿼터·지연이 사이트 수만큼 곱해집니다.

## 언제 돌리나

로컬 또는 CI에서 **가끔**만 실행합니다. 매일 배포마다 돌리지 마세요.

```bash
# .env.local 에 DATA_GO_KR_KEY=발급키
npm run facts:build
```

결과는 `src/lib/public-facts-data.ts`에 커밋합니다. 글 생성·지역 허브(`/region/[slug]`)는 이 파일을 읽습니다.

연결 확인만 할 때:

```bash
node --env-file=.env.local scripts/build-public-facts.mjs --probe
```

## 활용신청할 데이터셋

공공데이터포털에서 활용신청 후 같은 키로 호출합니다. 업종별로 필요한 것만 신청하면 됩니다.

| 용도 | 포털에서 찾을 이름 | 스크립트 경로(지방인허가 MOI) |
| --- | --- | --- |
| 동물병원 | 동물병원 인허가 / 지방행정인허가 | `animal_hospitals` (이미 사용) |
| 동물미용 | 동물미용업 인허가 | `pet_grooming` (이미 사용) |
| 일반음식점 | 일반음식점 인허가 | `general_restaurants` (이미 사용) |
| 미용업 | 미용업 인허가 | `beauty_salons` (probe에 있음, 승인 후 main에 추가) |
| 관광숙박 | 관광숙박업 인허가 | `tourist_accommodations` (이미 사용) |
| 동물판매업 | 동물판매업 인허가 | 승인 후 경로명 확인 → 스크립트 주석 참고 |
| 동물생산업 | 동물생산업 인허가 | 승인 후 경로명 확인 → 스크립트 주석 참고 |
| 동물위탁관리 | 동물위탁관리업 인허가 | 승인 후 경로명 확인 → 스크립트 주석 참고 |
| 유기동물 | 국가동물보호정보시스템 유기동물 조회 | `abandonmentPublicService_v2` (이미 사용) |
| 보호센터 | 동물보호센터 정보 | `animalShelterSrvc_v2` (이미 사용) |
| 관광지 | 한국관광공사 TourAPI 지역기반 관광정보 | `KorService2` (이미 사용) |

신청 화면의 서비스 URL·인증키만 받고, **서버리스 페이지에서 fetch 하지 마세요.**

## 글에 어떻게 붙나

생성(대량·허브·수동)이 끝나면 서버가 본문 HTML 끝에 공공·지역 표를 넣습니다. 제미나이가 표를 빼도 숫자가 남습니다. 상호·주소를 지어내지 않습니다.
